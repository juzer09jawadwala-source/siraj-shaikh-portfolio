## 🎙️ About The Project

This repository hosts the official portfolio of **Siraj Shaikh**, a professional commentator and anchor. The website is built with a strong focus on aesthetics, smooth interactions, and performance, delivering an engaging cinematic user experience. 

It was built entirely from scratch using native web technologies and infused with modern design trends like glassmorphism and Apple-inspired typographic styles.

### ✨ Key Features

- **Gooey Search & Navigation:** Custom-built SVG gooey effects for interactive header buttons.
- **Apple "Hello" Typography:** Premium cursive fonts used seamlessly in hero sections.
- **Voice Demo Player:** A built-in audio player for showcasing live commentary tracks.
- **Cinematic Scroll Animations:** Smooth, stacked-section scrolling without heavy dependencies.
- **Glassmorphism UI:** Modern frosted-glass design elements throughout the navigation and modals.
- **Responsive Design:** Beautifully optimized for desktop, tablet, and mobile viewing.
